# Gate5 提出物

## 1. 起動手順

このリポジトリには Google Apps Script のソース3ファイル（`appsscript.json` / `index.html` / `コード.js`）のみを含む。
配布済みスプレッドシートが無い課題のため、新しい Apps Script プロジェクトにこのコードを配置すると、
`ensureSetup_()` が自動でシートと初期データを作成する。

1. 新しい Google スプレッドシートを作成し、「拡張機能 → Apps Script」を開く（＝コンテナバインド型スクリプトができる）
2. エディタ上のファイルをこの3ファイルの内容に置き換える（`コード.js` → スクリプト本体、`index.html` → HTMLファイル、`appsscript.json` → マニフェスト。マニフェストは「プロジェクトの設定」で「"appsscript.json" マニフェストファイルをエディタで表示する」を有効にすると編集できる）
3. エディタ上で `ensureSetup_` 関数を選び、実行ボタン（▷）を押す（初回のみ。シートと初期データが作成される）
4. 「デプロイ → 新しいデプロイ」から Web アプリとしてデプロイし、発行された URL を開く

※ 本課題では動作確認のため一時的に Web アプリとしてデプロイしていたが、社外公開の懸念があったため**提出前にデプロイを削除済み**。
　提出物はこのソースコード3ファイルそのものであり、URL は提出に使用していない。
